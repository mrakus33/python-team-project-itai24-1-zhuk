# Student and Grade Accounting
## Project Description
This is a console application designed to manage student academic records. It allows users to input student names and their corresponding grades, calculates each student's average score, and outputs a sorted ranking of students based on their academic performance. 
This project was developed as part of Practical Lesson 6 to demonstrate team software development skills using Git and GitHub.
## Functionality
* Adding students and their grades via the console.
* Calculating the average score for each student.
* Sorting the list of students by their average score (from highest to lowest).
* Handling basic input errors (e.g., preventing non-numeric grades).
